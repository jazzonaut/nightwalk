# Code of Conduct

This project follows the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful. Disagree about ideas, not about people.
- No harassment, discrimination, or personal attacks.
- Assume good faith. Ask questions before assuming malice.
- Keep discussion on-topic and constructive.

Maintainers may edit, remove, or close comments, issues, and pull requests, or block contributors who violate this code.

## Reporting

To report a problem, open a GitHub issue with the `needs-triage` label and the title prefix `[CoC]`, or contact [@jazzonaut](https://github.com/jazzonaut) via GitHub.
